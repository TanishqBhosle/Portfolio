## ⚡ Overview

This interactive portfolio demonstrates modern web engineering practices with a futuristic, cyberpunk-inspired dark aesthetic. It features interactive 3D WebGL particle fields, magnetic micro-interactions, modal inspection cards, and full mobile responsiveness.

### 🌟 Key Highlights

- **Interactive 3D Particle Field**: WebGL particle canvas built with Three.js responsive to cursor interaction and fluid dynamics.
- **Project Showcase & Deep-Dive Modals**: Comprehensive cards for production systems including **Shield AI**, **HoneyChain**, **TelcoRetain**, **SkinSolve**, and **Voice Agent Sarthi**.
- **Interactive Skills Matrix**: Multi-category skill breakdown with proficiency meters, domain tags, and dynamic category filtering.
- **Milestone Timeline**: Chronological track of academic foundation, certifications, hackathons, and engineering projects.
- **Direct Transmission Console**: Interactive contact form with one-click email copy, confetti particle celebration, and direct mail link dispatch.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/) or [pnpm](https://pnpm.io/)

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/TanishqBhosle/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
